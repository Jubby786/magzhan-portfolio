# Magzhan Turganbay — Creative Portfolio

A responsive English-language personal portfolio for Magzhan Turganbay, a Smart Technologies student at Astana IT University.

## Website

After enabling GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**, the site URL is:

https://jubby786.github.io/magzhan-portfolio/

## Tech stack

HTML, CSS and JavaScript. No build step required.

## Local preview

Download or clone the repository and open `index.html` in a browser.

## Content

About, projects and experience, skills, education and contact placeholder. Contact details and unverified achievements have intentionally not been invented.
